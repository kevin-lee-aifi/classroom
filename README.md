# Classroom

A personal knowledge base for tracking papers, learning journeys, and teaching resources in biology and related fields.

## Structure

```
papers/
  <paper-slug>/
    README.md          — paper record: metadata, abstract, key concepts, status
    paper.pdf          — the paper itself
    notes/
      learning-plan.md — structured study plan
    resources/         — links, related papers, datasets
```

## Conventions

- One folder per paper, named as a lowercase hyphenated slug of the title.
- `README.md` in each paper folder is the canonical record for that paper.
- Learning status: `to-read` → `reading` → `read`.
- Notes live in `notes/` as markdown files.
